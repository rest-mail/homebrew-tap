# rest-mail Homebrew tap

```sh
brew install rest-mail/tap/restmail
```

`restmail` is the command-line tool for running a rest-mail server: claiming
a fresh install (`restmail setup`), and getting back in as its admin when
every other way is lost (`restmail reset-admin`).

Nothing here is edited by hand. Each release of
[rest-mail-server](https://github.com/rest-mail/rest-mail-server) updates it.
